# ARAN’26 v8.16.7 – Production

Official signed Android release for **ARAN’26 – 30th State Level Home Guards Professional and Sports Meet**.

## Release changes

- Driver participant type and Driver rank/designation added.
- Driver registration requires no event selection and remains within the 120-participant range cap.
- Female participants retain all-three-sports selection.
- Male event-selection rules remain unchanged.
- 16 km Cross Country roster remains **4 main + 2 reserve**.
